Trabalho Prático 2 – Back-End 
Sistema WEB integrado com Banco de Dados 
O TRABALHO PRÁTICO 2 CORRESPONDE A NOTA DA P2 
O Trabalho Prático 2 consiste em implementar um Sistema WEB completo integrado 
com Banco de Dados. Nas aulas da disciplina, foram estudados: Front-End e Back-End, 
nesse cenário você e seu grupo devem escolher um Sistema WEB e implementar tanto o 
Front-End como o Back-End utilizando os conhecimentos adquiridos ao longo do semestre. 
O Trabalho deve ser realizado em grupo de DOIS alunos  
(em casos particulares na formação do grupo consulte o professor da disciplina 
antes de iniciar o desenvolvimento). 
ENTREGAR: Por meio da plataforma TEAMS até a aula do dia: 19/11/2026 
✓ Entregar todo o código em ZIP ou RAR 
✓ Entregar o Backup da Base de Dados 
✓ Entregar o link do repositório do projeto no GitHub 
✓ Apresentar o Trabalho na aula do dia 19/11/2026 
Tecnologias utilizadas: Você deve poderá utilizar a Linguagem de Marcação 
(HTML), Linguagem de Estilo (CSS), Linguagem de Script (JavaScript) e framework 
Bootstrap para implementar o Front-End. Entretanto para o Back-End é obrigatório o uso da 
Linguagem PHP, Método POST, Variáveis de Session, integração com Banco de Dados 
(MySQL). Git e GitHub para versionamento de software. 
O USO DO GIT E GITHUB É OBRIGATÓRIO!!! CASO NÃO UTILIZAR SERÁ 
ATRIBUIDO NOTA ZERO PARA O GRUPO!!! 
Especificações obrigatórias: O seu sistema deve conter obrigatoriamente: 
✓ Login de usuário(s) (Com persistência em Banco de Dados) 
✓ Recuperar senha, quando o usuário esquecer sua senha, deve ser possível 
recuperar a mesma ou realizar o processo de trocar a senha. 
✓ No mínimo quatro telas de cadastro com persistência em Banco de Dados, 
pense no exemplo do Sistema Xhopii (Existem três cadastros: Cliente, Produto 
e Funcionários) 
✓ No mínimo quatro telas de visualização de cadastro, ou seja, recuperação dos 
dados existentes no Banco de Dados e exibição em páginas WEB. 
✓ Implementar duas funcionalidades específicas de sua temática, cada grupo 
possui um tema de sistema validado pelo professor, implemente uma 
funcionalidade dessa temática. Exemplo: No Sistema Xhopii uma 
funcionalidade da temática de e-commerce é realizar uma venda. 
✓ DESAFIO!!! – IA – Implementar uma funcionalidade que consuma a IA 
generativa do GEMINI
